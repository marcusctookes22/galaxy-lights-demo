# Galaxy Car Lights Demo

A lightweight static GitHub Pages demo for Galaxy Car Lights.

## Production structure

- `index.html` — semantic page content and metadata
- `styles.css` — complete responsive visual system
- `app.js` — navigation, FAQ, starlight studio, canvas effects, and quote-summary behavior
- `galaxy-brand-logo.js` — approved Galaxy logo data asset
- `galaxy-logo.svg` — local fallback logo

The demo intentionally avoids build tooling, runtime HTML fragments, stacked theme patches, and runtime translation layers so it can deploy reliably on GitHub Pages.
